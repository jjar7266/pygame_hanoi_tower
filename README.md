## 📌 Description
A fully animated Tower of Hanoi built with Pygame, designed as a structured learning project and a personal reference for future development. Each stage demonstrates clear progression, clean OOP design, modal UI windows, and a polished final version.

## 🎮 Overview
This project recreates the Tower of Hanoi puzzle using Pygame with a focus on readability, progression, and practical architecture. It includes modal popups, animated disk movement, and a step-by-step evolution from basic rendering to a complete interactive application.

## ✨ Features
• Smooth animated disk movement
• Modal popup system for user interaction
• Clean object-oriented structure
• Step-by-step development progression
• Puzzle solver and manual play modes
• Organized Pygame base template
• Final polished version included

## ▶️ Running the Project
Install Pygame:

pip install pygame

Run the final version:

python hanoi_oop_step8_main.py

## 📚 Purpose
This repository serves as a personal reference documenting the full journey of building a complete Pygame application. It is also a helpful guide for anyone learning Pygame, OOP design, or UI structure.
